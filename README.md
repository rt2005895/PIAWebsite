# Pakistan International Airlines (PIA) Website

## Project Overview

This project is a frontend recreation inspired by the official website of Pakistan International Airlines (PIA). It is developed as a practice project to improve frontend development skills by combining HTML, CSS, and JavaScript.

The website provides an airline-style interface with a navigation menu, flight booking section, promotional banners, announcements, and other informational sections. The design focuses on a clean layout, user-friendly navigation, and interactive elements.

This project demonstrates how different frontend technologies work together to create a complete and interactive website.

## Technologies Used

The following technologies were used to develop this project:

- **HTML5:** Used to create the website structure and organize different sections.
- **CSS3:** Used for styling, layouts, colors, typography, animations, and responsive design.
- **JavaScript:** Used to add interactivity and handle website features such as dropdown menus, booking tabs, and announcement carousel functionality.

## How to Run the Project

Follow these steps to run the website on your computer:

1. Download or clone this repository.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder in Visual Studio Code.
4. Make sure all project files and the Media folder are in their correct locations.
5. Open the `index.html` file in your browser.
6. You can also use the Live Server extension in Visual Studio Code to preview the website.

## Project Objectives

The main objectives of this project are:

- To understand the structure of a complete frontend website.
- To practice semantic HTML and proper page organization.
- To improve CSS styling and layout development skills.
- To implement JavaScript-based interactive features.
- To understand how HTML, CSS, and JavaScript work together.
- To practice responsive web design using CSS media queries.
- To gain practical experience in developing and organizing a frontend project.

## Limitations

- This project focuses only on frontend development.
- It does not include a backend system or database.
- The flight booking interface is for demonstration purposes only.
- No real flight reservations or ticket purchases can be made.
- Forms and booking fields are not connected to an airline reservation system.
- The website does not process payments or manage passenger information.
